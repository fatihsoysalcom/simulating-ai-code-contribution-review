# Simulating AI Code Contribution Review

This example simulates the challenges faced by open-source project reviewers when evaluating AI-generated code contributions. It contrasts a concise, focused 'human' pull request with a verbose, generic 'AI-like' one. A simple 'reviewer' function highlights common patterns in AI-generated code that can lead to reviewer fatigue and potential rejection.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
